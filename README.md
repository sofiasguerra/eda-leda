# EDA UFCG

Repositório com meus estudos e exercícios da disciplina de **Estruturas de Dados e Algoritmos (EDA)** na UFCG.

## Sobre

Este repositório reúne os templates fornecidos pelo professor ao longo do semestre, junto com minhas implementações e modificações.

## tst-leda

A pasta `tst` é um banco de questões variadas sobre os assuntos da disciplina. As resoluções em código ficam centralizadas em um arquivo próprio, onde vou implementando as soluções conforme resolvo cada questão.
